# Limitwen Homebrew tap

Install [Limitwen](https://github.com/uzair166/limitwen-app), a native macOS menu bar app for Claude Code and Codex subscription usage limits.

```sh
brew tap uzair166/tap
brew install limitwen
limitwen
```

Requires macOS 14 or newer and Apple developer tools with Swift 6. The formula compiles source locally; it does not download a prebuilt app or change macOS security settings. Quit the app before upgrading.

This is a custom tap, not Homebrew core. The app and formula use the [0BSD license](LICENSE), with no attribution requirement.
